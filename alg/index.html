Algebraic Reasoning in
Neural Networks and LSTMs

Can neural networks learn step-by-step algebraic manipulation?

Aaron Branson Cigres Li · HKUST · Summer 2023

Problem & Approach

The Challenge

Existing neurosymbolic models (Lample 2019, Charton 2021) predict final answers but treat reasoning as a black box.

Can we build a model that reasons one step at a time, producing transparent intermediate steps?

Key Idea

Train a neural network to predict the next algebraic manipulation step, not the final answer.

Chain predictions iteratively: output becomes input until the target expression is reached.

Representation Pipeline

Expressions are converted through three stages before entering the model

Standard Form
A = B + C * D
→
Polish Notation
Removes parentheses,
fixes expression length
= A * + B C D
→
Binary Matrix
6×8 selection +
permutation matrices
$\mathbb{V}^{6 \times 8}$
→
Neural Network
Input: 2 matrices
Output: 1 matrix (next step)

Space limited to equations with 4 variables (A, B, C, D) and 2 operators (+, -, *, /)

Dataset Generation

Algorithmically Generated

  • Enumerate all valid 6×8 binary matrices
  • Filter: must convert to valid expressions
  • Group by equivalence (verified via SymPy)
  • Measure distance using modified Levenshtein (minimum element repositions)
  • 4 datasets by reasoning distance (1-4 steps)

Model Architecture & Training

Architecture Search

Tested 4 to 9 layer feedforward networks. 5-layer model chosen — fastest convergence, smallest architecture.

Flatten(2, 6, 8)
Dense(96, relu)
Dense(96, relu) × 2
Dense(48, relu)
Dense(48, sigmoid)
Reshape(6, 8)

Loss: MSE · Optimizer: Adam · 100K epochs

Loss converges around 10,000 epochs — model chosen at 7,000 epochs

Key Finding: Sequential Reasoning Overfitting

As training progresses, 1-step accuracy keeps improving while 4-step accuracy peaks then declines

Epochsx1 test (1-step)x2 test (2-step)x3 test (3-step)x4 test (4-step)

Novel overfitting symptom: not just a train/test gap, but a trade-off between short-term and long-term reasoning. x4 peaks at 7,000 epochs then declines by 37% at 100K, while x1 keeps climbing. Model selected at 7,000 epochs (sweet spot).

LSTM Improvement

Why LSTM?

Feedforward models hit a ceiling. LSTMs are designed for sequential data processing — a natural fit for step-by-step reasoning.

LSTM(96, input=(2, 48))
Dense(500 → 400 → 300 → 200 → 100, relu)
Dense(48, sigmoid)

Summary

  • Designed an algorithmically defined expression space using Polish notation and binary matrix representations for 4-variable, 2-operator equations
  • Built data generation pipeline with equivalence verification (SymPy) and modified Levenshtein distance for step measurement
  • Identified a novel sequential reasoning overfitting: accuracy on 1-step problems improves while 4-step problems degrade — a trade-off between short-term and long-term reasoning
  • LSTM layer improved overall test accuracy from 39% to 64%, with the biggest gains on multi-step problems
